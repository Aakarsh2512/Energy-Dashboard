# Energy & Oil Trading Dashboard

A demonstration dashboard for an energy and oil prop trading desk.
Built by Aakarsh Varshney.

## Setup

1. Create venv: `python -m venv venv`
2. Activate: `.\venv\Scripts\Activate.ps1`
3. Install: `pip install -r requirements.txt`
4. Run: `streamlit run src/app.py`

## Structure

- `src/` — application code
- `data/` — cached data files
- Notebooks for prototyping live separately on Google Colab
